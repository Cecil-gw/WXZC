#### 一。损失函数

##### 回归任务（预测连续数值）

###### 1. L1 Loss 平均绝对误差 MAE

`torch.nn.L1Loss()`

* 公式：\(Loss=\frac{1}{N}\sum|y-\hat y|\)
* 特点：对**异常值鲁棒**，梯度恒定；零点附近梯度突变。
* 适合：数据噪声大，不希望被离群点带偏。

###### 2. MSE Loss 均方误差 L2 损失

`torch.nn.MSELoss()`

* 公式：\(Loss=\frac1N\sum(y-\hat y)^2\)
* 特点：误差越大惩罚越重；**对离群点很敏感**；处处可导。
* 最常用回归损失。

###### 3. SmoothL1Loss（Huber Loss）⭐推荐

`torch.nn.SmoothL1Loss()`

* 结合 L1 和 MSE。误差小时用 MSE，误差大时切换 L1。
* 优点：兼顾可导 + 抗异常值；目标检测（Faster‑RCNN 框回归）标配。

* * *

##### 分类任务（最常考）

###### 1. 二分类：BCELoss / BCEWithLogitsLoss

1. `BCELoss`：输入必须已经经过 sigmoid（0~1 概率）

2. **`BCEWithLogitsLoss`【优先用】**：自带 sigmoid，输入是原始 logit，数值稳定性更好。
* 使用场景：
  
  * 二分类；
  * **多标签分类**：一个样本可以同时属于多个类别。

> label 不用 one‑hot，直接 0/1。

###### 2. 多分类：CrossEntropyLoss 交叉熵损失 ⭐最重要

`torch.nn.CrossEntropyLoss()`

* **内部自带 softmax**，网络输出直接给 logits，**不要自己加 softmax**。
* target 是类别索引（数字 0,1,2…），不需要 one‑hot 编码。
* 场景：单标签多分类，一张图只属于一类。

> 易错区分：
> 
> * CrossEntropyLoss = log_softmax + NLLLoss
> * NLLLoss：输入要先 log_softmax，很少直接用。

###### 3. 负对数似然 NLLLoss

`torch.nn.NLLLoss()`

需要你网络输出做完`log_softmax`再喂进去。一般不直接用，CrossEntropy 底层就是它。

###### 4. MultiLabelSoftMarginLoss

多标签分类另一种实现。

* * *

##### 其他常用损失

###### 1. CTCLoss

`torch.nn.CTCLoss()`

序列对齐，OCR 文字识别，语音识别。输入序列长度和标签长度不等，不需要对齐。

###### 2. KLDivLoss KL 散度

`torch.nn.KLDivLoss()`

衡量两个分布差异，知识蒸馏、概率分布拟合。输入需要 log 概率。

###### 3. MarginRankingLoss

排序任务，对比两个样本谁分数更高。

###### 4. DiceLoss / IoU Loss（不在 nn 原生库，自己实现）

分割任务，样本不均衡场景。医学图像分割高频使用。

###### 5. TripletLoss 三元组损失

度量学习，人脸识别。输入：锚样本、正样本、负样本。让同类靠近，异类远离。



#### 二。感知机



. 是什么
-----

感知机（Perceptron），**1957 Rosenblatt 提出**，是最简单的**二分类线性判别模型**，神经网络最基础的单元。

任务：找一个超平面，把样本分成两类。

* * *![217090f8-d5ac-44f7-b6f4-93c292af08f6](file:///C:/Users/HP/Downloads/217090f8-d5ac-44f7-b6f4-93c292af08f6.png)

2. 几何意义

-------

* 2 维：决策边界是**直线** \(w_1x_1 +w_2x_2 +b=0\)
* 3 维：决策边界是平面
* n 维空间：**超平面**

> 核心约束：**只能处理线性可分数据集**。
> 
> 样本必须可以被一个超平面完全切开。
> 
> ❌ XOR 异或问题线性不可分 → **单层感知机无法解决 XOR**。

3. 损失函数（重点）

-----------

感知机**只对误分类样本计算损失**，分对的样本不贡献 loss。

样本标签 \(y_i\in\{+1,-1\}\)

当样本被分错时：\(y_i(\boldsymbol w^\mathrm T\boldsymbol x_i +b)\le 0\)

损失：

![a7f80717-7d0d-4d99-8540-d20eb4ab597f](file:///C:/Users/HP/Downloads/a7f80717-7d0d-4d99-8540-d20eb4ab597f.png)

* 全部样本分类正确：损失 = 0。

> 注意：这不是 MSE，不是交叉熵，**只拿分错的点求和**。

4. 参数更新（随机梯度下降）

---------------

学习率 \(\eta>0\)，遍历每一个误分类样本，更新 w、b：

\(\begin{aligned}\boldsymbol w &\leftarrow \boldsymbol w + \eta\, y_i \boldsymbol x_i \\b &\leftarrow b + \eta\, y_i\end{aligned}\)

逻辑：遇到错分样本，向着把这个样本分对的方向调整权重。

终止条件：**没有误分类点，损失为 0，算法收敛**。

👉 收敛定理：**只要数据集线性可分，感知机算法一定能收敛**；线性不可分，永远震荡不收敛。

5. 单层感知机 VS 多层感知机 MLP

---------------------

1. **单层感知机**
* 结构：输入层 →输出层，无隐藏层；激活是阶跃函数。
* 能力：仅线性可分二分类，解决不了 XOR。
* 历史痛点：Minsky 指出不能解 XOR，直接引发第一次 AI 寒冬。
2. **多层感知机 MLP（全连接网络）**
* 增加**隐藏层**，把阶跃换成**非线性激活（ReLU/sigmoid）**。
* 可以拟合非线性，能解决 XOR。

> ⚠️如果没有非线性激活，再多层等价一层线性模型。

6. 面试高频问答（必背）

-------------

### Q1：感知机损失函数和交叉熵 / MSE 有什么区别？

感知机**只使用误分类样本**；交叉熵 / MSE 所有样本都参与计算损失。

### Q2：为什么单层感知机不能解决 XOR？

XOR 样本是线性不可分，单层感知机决策边界只能是超平面，不存在直线把两类分开。加入隐藏层 + 非线性激活（MLP）可以解决。

### Q3：感知机什么时候收敛？

**数据集线性可分时，一定会收敛；线性不可分永远不收敛。**

### Q4：感知机和逻辑回归的区别？

1. 感知机：输出\(\pm1\)，阶跃激活；损失基于误分类点；目标找分离超平面。
2. 逻辑回归：输出概率 0~1，sigmoid；损失是交叉熵；输出类别概率。

### Q5：感知机更新规则记忆

碰到分错样本：\(w \mathrel{+}= \eta y_i x_i\)，\(b\mathrel{+}= \eta y_i\)

7. 容易踩坑点

--------

1. 标签是 \(+1,-1\)，**不是 0 和 1**。（逻辑回归用 0/1，感知机原始定义用 ±1）
2. 损失**只累加错分样本**，正确样本不算。
3. 单层感知机没有隐藏层！不要和 MLP 搞混。
4. 阶跃函数不可导，现实神经网络几乎不用阶跃，改用 ReLU/sigmoid

    多层感知机 MLP（多分类，李沐课件版）先看懂图上全部符号：
    n：输入特征数
    m：隐藏层神经元个数
    k：类别总数（输出神经元数量）
    
    和上一张「单分类」对比：
    单分类输出层是向量\(\boldsymbol w_2\)、标量\(b_2\)，输出 1 个数；
    多分类输出层变成矩阵\(\boldsymbol W_2\in \mathbb R^{m\times k}\)，偏置\(\boldsymbol b_2\in\mathbb R^k\)，输出k个值。
    公式逐行拆解
    \(\boldsymbol h = \sigma(\boldsymbol W_1\boldsymbol x+\boldsymbol b_1)\)
    
    \(\underbrace{\boldsymbol W_1}_{m\times n}\underbrace{\boldsymbol x}_{n\times1}+\underbrace{\boldsymbol b_1}_{m\times1} \Rightarrow \boldsymbol h_{m\times1}\)
    \(\boldsymbol W_1\)：隐藏层权重，m行n列
    \(\boldsymbol b_1\)：隐藏层偏置，m维向量
    \(\sigma\)：按元素做的非线性激活（ReLU/Sigmoid）
    
    
    ⚠️没有\(\sigma\)，两层线性可以合并，网络退化成单层线性模型，不能拟合非线性（解决不了 XOR）。
    
    \(\boldsymbol o = \boldsymbol W_2^T \boldsymbol h + \boldsymbol b_2\)
    \(\boldsymbol W_2\)形状是 \(m\times k\)，转置\(\boldsymbol W_2^T\)之后是 \(k\times m\)
    
    \(\underbrace{\boldsymbol W_2^T}_{k\times m}\underbrace{\boldsymbol h}_{m\times1}+\underbrace{\boldsymbol b_2}_{k\times1} \Rightarrow \boldsymbol o_{k\times1}\)
    \(\boldsymbol o\) 叫logits：k维向量，每个数字代表对应类别的原始得分，还不是概率。
    
    \(\boldsymbol y = \mathrm{softmax}(\boldsymbol o)\)
    softmax(o)：把k个 logit 得分，转换成k个 0~1 之间的概率，全部概率相加等于 1。
    
    \(y_i=\frac{\exp(o_i)}{\sum_{j=1}^k\exp(o_j)}\)完整网络流程（多分类 MLP）输入\(\boldsymbol x\) → 隐藏层线性变换 → 非线性激活\(\sigma\) →输出层线性变换得到 logits\(\boldsymbol o\) → softmax 得到各类别概率\(\boldsymbol y\)。
    PyTorch 注意：CrossEntropyLoss内部自带 softmax，训练的时候不要自己写 softmax，直接喂 logits \(\boldsymbol o\)进去。
    🆚 单分类 vs 多分类 MLP
    
    表格项目单分类（二分类）多分类输出层权重向量\(\boldsymbol w_2\in\mathbb R^m\)矩阵\(\boldsymbol W_2\in\mathbb R^{m\times k}\)输出层偏置标量\(b_2\)向量\(\boldsymbol b_2\in\mathbb R^k\)输出o1 个数字（标量 logit）k维 logit 向量后处理不用 softmax，用 sigmoidsoftmax损失函数BCEWithLogitsLossCrossEntropyLossMLP 核心知识点（面试）
    
    为什么需要隐藏层 + 非线性激活？
    没有非线性激活，不管堆多少层，等价单层线性模型，只能处理线性可分任务，无法拟合 XOR 等非线性问题。非线性是多层网络表达能力的来源。
    
    
    softmax 作用
    把任意实数的 logits，映射成总和为 1 的概率分布。
    
    
    CrossEntropyLoss = softmax + NLLLoss
    PyTorch 已经封装好，输入直接传 logits \(\boldsymbol o\)，target 传类别索引，不要手动 softmax。
    
    
    MLP 的限制
    
    
    全部是全连接，参数量爆炸；
    没有利用空间、序列结构信息，图片任务不如 CNN，序列不如 RNN/Transformer。

1️⃣ 为什么需要隐藏层 + 激活函数
-------------------

* 只有**隐藏层**，网络才有能力表达更复杂映射；
* **激活函数提供非线性**。

> 如果去掉激活函数，无论堆多少层，多层网络等价于单层线性模型，无法拟合 XOR 这类非线性问题。

2️⃣ 三大激活函数对比
------------

表格

| 激活函数    | 公式                                         | 输出范围       | 特点                           |
| ------- | ------------------------------------------ | ---------- | ---------------------------- |
| Sigmoid | \(\sigma(x)=\frac{1}{1+e^{-x}}\)           | \((0,1)\)  | 容易梯度消失；早期用，现在少用于隐藏层；适合二分类输出层 |
| Tanh    | \(\tanh(x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}\) | \((-1,1)\) | 零均值，但依然存在梯度消失                |
| ReLU    | \(\mathrm{ReLU}(x)=\max(0,x)\)             | $          |                              |

[0,+\infty)$|**最常用**；正区间无梯度消失；计算快；会出现神经元死亡 |

> 💡注意：激活函数是**按元素运算**，每一个神经元输出单独做变换。

3️⃣ Softmax
-----------

* 作用：接收多分类原始得分 logits，输出一组总和等于 1 的概率分布。
* 搭配：多分类任务，PyTorch 中`CrossEntropyLoss`内部已经集成 softmax，训练代码不要重复写 softmax。

4️⃣ MLP 的超参数（人为设定，模型不能自己学）
--------------------------

1. **隐藏层数**：到底设置几层隐藏层（1 层、2 层、3 层…）
2. **各隐藏层大小**：每一层设置多少个神经元（\(m_1,m_2...\)）

> ⚠️区分：
> 
> * **模型参数（可学习）**：权重\(\boldsymbol W\)、偏置\(\boldsymbol b\)，反向传播更新；
> * **超参数（人工调）**：隐藏层数、神经元数量、学习率、batch_size，需要人工搜索调参。

📝面试速记
------

1. MLP 获得非线性能力的来源：**隐藏层 + 非线性激活函数，二者缺一不可**。
2. 隐藏层优先选 ReLU；Sigmoid/Tanh 现在很少做隐藏层激活。
3. Softmax 用于多分类输出；不要和 CrossEntropyLoss 重复使用。
4. 隐藏层数、每层神经元数量，属于超参数，不是训练出来的。

#### 三。模型容量、欠拟合、过拟合、泛化能力

1. 基础概念

-------

**模型容量**：代表模型的拟合能力。

MLP 里：隐藏层越多、每层神经元越多 → 模型容量越大，能学习更复杂的规律。

**训练误差**：模型在**训练数据集**上算出来的误差，看模型能不能记住训练样本。

**泛化误差**：模型在**没见过的测试集 / 真实新数据**上的误差。我们真正关心的就是泛化误差。

> 训练误差低 ≠ 模型好用。模型可以死记训练数据，但遇到新样本直接翻车。

* * *

2. 结合图像理解曲线

-----------

横轴向右：模型容量不断变大

1. **训练误差曲线**
   容量越大，模型本事越强，训练集可以学的越来越准，**训练误差持续下降**。哪怕模型过拟合，训练误差依旧会很低。

2. **泛化误差（U 型曲线）**
* 一开始容量小：泛化误差高；随着容量增加，泛化误差下降，到达最低点（最优点）
* 继续增大容量：泛化误差不降反升，就是过拟合。

### ①欠拟合（图左边）

模型容量太小，能力不够，连训练集里面的底层规律都学不会。

* 表现：**训练误差高，泛化误差也高**
* 现象：训练的时候 loss 降不下去，训练集效果就很差。
* 解决：提高模型容量（加神经元、加隐藏层）；调优超参数；增加训练迭代。

### ②最优点（虚线）

泛化误差取最小值。

训练误差和泛化误差差距不大，模型学到通用规律，既没有没学好，也没有死记硬背。这是我们想要的状态。

### ③过拟合（图右边）

模型容量过大，能力太强。不仅学习数据真实规律，还记住训练集独有的噪声、随机误差、特例。

* 表现：**训练误差很低，泛化误差很高**
* 现象：训练集准确率极高；跑测试集效果暴跌。

> 举例子：背题，把练习题全部背下来，练习题满分，但是遇到全新考试题就考很差。

* 解决过拟合的 5 个核心方法
1. 获取更多训练数据（最有效）
2. 降低模型容量：减少神经元、减少层数
3. 正则化（权重衰减 L2，L1 正则），限制权重不要变得太大
4. Dropout：训练时随机关掉一部分神经元，防止模型过度依赖某些特征
5. 早停 Early‑Stopping：监控验证集误差，当验证误差开始上升，立刻停止训练

* * *

3. 面试必背对比表

----------

表格

| 项目   | 欠拟合         | 过拟合                      |
| ---- | ----------- | ------------------------ |
| 根本原因 | 模型容量不足      | 模型容量过大，记住噪声              |
| 训练误差 | 高           | 很低                       |
| 泛化误差 | 高           | 高                        |
| 两者差距 | 差距不大，都高     | 差距巨大，训练很好，测试差            |
| 解决思路 | 增大模型复杂度，多训练 | 正则、dropout、扩增数据集、早停、减小模型 |

4. 易错理解

-------

1. ❌错误：过拟合是训练时间太长，欠拟合是训练时间太短。
   ✅正确：容量是主导因素。容量很小，训再久也是欠拟合；容量很大，训很短也可能轻微过拟合。训练轮次只是放大这个现象。

2. ❌错误：目标把训练误差降到 0。
   ✅正确：我们追求**泛化误差最小**，训练误差低只是副产品。

3. ❌错误：模型越大效果一定越好。
   ✅正确：模型容量超过最优点之后，越大泛化能力越差。

5. 补充验证集概念

----------

实际工程不会只看训练、测试集。

把数据分成三份：

* 训练集：用来更新权重
* **验证集**：用来选模型、调超参数，监控是否过拟合，用来做早停
* 测试集：只最后使用一次，评估最终真实泛化能力

> 不能拿测试集调参，不然会把测试集的信息泄露给模型，测试集失去参考意义。



#### 四。VC 维（VC‑dimension）

课件定义
----

> 对于一个分类模型，VC 维等于**最大的数据集大小**，不管如何给定标号，都存在一个模型来对它进行完美分类。

### 通俗翻译

VC 维：这个模型最多能够 ** 完全打散 (shatter)** 多少个样本点。

* **打散 (shatter)**：不管你给这 N 个点随便分配什么标签（0/1 的所有组合），模型都能 100% 把它们分开。
* 如果存在一组 N 个点可以被打散；但是**任意 N+1 个点都做不到打散**，那么该模型 VC 维 = N。

* * *

举简单例子
-----

1. 二维平面上的线性分类器（直线做二分类）
* 最多可以完美打散**3 个点**（任意标签都可以用一条直线分开）

* 4 个点无论如何摆放，总有一种标签组合，直线无法分割。
  👉二维线性分类器 VC 维 = 3。

> VC 维和参数数量有相关性，但**不完全等于参数个数**。

和前面「模型容量、过拟合」的关系⭐（重点，面试）
------------------------

1. **VC 维代表模型理论容量**
   VC 维越大，模型的表达能力越强，可以拟合更复杂的数据，越容易发生**过拟合**。
* VC 维小：模型容量低，容易欠拟合；
* VC 维大：模型容量高，容易过拟合。
2. 统计学习理论结论：
   泛化误差上界和两件事有关：
* VC 维（模型本身能力）
* 训练样本数量 N

> 样本数量固定时，VC 维越大，泛化误差的上界会变大，过拟合风险上升。
> 
> 想要泛化好：样本量要显著大于模型 VC 维。

关键理解点
-----

1. VC 维是**模型 / 假设空间的属性**，不是某一组训练数据的属性。
2. 不需要所有大小为 N 的数据集都能打散，**只要存在某一组 N 个点可以被打散**，就算达到。只要有任意一组 N+1 个点无法打散，VC 维就停在 N。
3. VC 维主要是理论工具；深度学习几乎不会直接计算 VC 维（深度网络 VC 维巨大），更多用来做定性理解：**模型容量越高，过拟合风险越大**。

面试简答模板
------

> VC 维是统计学习理论用来衡量模型容量的指标。它指能够被模型打散的最大样本数目。打散代表：对于这组样本，无论怎么分配标签，模型都可以完美分类。VC 维越大，模型表达能力越强，越容易过拟合。
