##### 1.判断智能体回复的评判标准

|             | 代码客观评估                            | LLM 作为裁判主观评估                                   |
| ----------- | ---------------------------------:| ---------------------------------------------- |
| ✅每条样本有标准答案  | 拿代码直接比对输出和真实答案，比如发票日期提取，相等就算正确    | 大模型统计输出里面包含多少标准要点，没有硬相等，是要点覆盖率打分               |
| ❌没有每条样本标准答案 | 写硬规则做检查，比如文案长度≤10 就加分，没有参考答案，只有规则 | 给大模型一套通用评分 rubric（评分细则），直接打分，**没有标准答案，只有评判标准** |
|             |                                   |                                                |
